# Table Size Calculator - Spark JobnnThis repository contains a Spark-based job for calculating table sizes across all databases in Databricks. The job was created to address Jira ticket **DTP-472**: "TEST- creating spark job for size".nn## OverviewnnThe `table_size_calculator.py` script connects to Databricks and calculates the size of all tables across all databases. It provides detailed information about table sizes, including row counts, data size, and storage location.nn## Featuresnn- **Comprehensive Analysis**: Analyzes all tables across all databases in the catalogn- **Detailed Metrics**: Provides row counts, data size in bytes/MB/GB, and storage locationn- **Database Summary**: Groups results by database with aggregate statisticsn- **Top Tables Report**: Identifies the largest tables by sizen- **Delta Table Output**: Saves results to a Delta table for further analysisn- **JSON Summary**: Generates a detailed JSON summary reportn- **Error Handling**: Robust error handling with detailed loggingn- **Configurable**: Highly configurable through JSON configuration filenn## Requirementsnn- Python 3.8+n- Apache Spark 3.4+n- Databricks Runtime or Spark cluster accessn- Required Python packages (see `requirements.txt`)nn## Installationnn1. Clone this repository:n   ```bashn   git clone <repository-url>n   cd testing-cursorn   ```nn2. Install dependencies:n   ```bashn   pip install -r requirements.txtn   ```nn3. Configure the job by editing `config.json`:n   ```jsonn   {n     "app_name": "TableSizeCalculator",n     "log_level": "INFO",n     "output_table": "default.table_size_analysis",n     "summary_output_path": "/tmp/table_size_summary.json"n   }n   ```nn## Usagenn### Running the Jobnn```bashnpython table_size_calculator.pyn```nn### Configuration OptionsnnEdit `config.json` to customize the job behavior:nn- `app_name`: Name of the Spark applicationn- `log_level`: Logging level (DEBUG, INFO, WARN, ERROR)n- `output_table`: Delta table name to save resultsn- `summary_output_path`: Path for JSON summary reportn- `spark_configs`: Additional Spark configurationsn- `databases_to_exclude`: List of databases to skipn- `table_size_threshold_mb`: Minimum table size to include in analysisn- `enable_detailed_logging`: Enable detailed logging for debuggingnn### OutputnnThe job generates two types of output:nn1. **Delta Table**: Detailed table size information stored in the specified Delta tablen2. **JSON Summary**: High-level summary report with statistics and top tablesnn#### Delta Table Schemann```sqlnCREATE TABLE table_size_analysis (n  database_name STRING,n  table_name STRING,n  table_type STRING,n  row_count BIGINT,n  data_size_bytes BIGINT,n  data_size_mb DOUBLE,n  data_size_gb DOUBLE,n  location STRING,n  created_time STRING,n  last_modified STRING,n  processed_at STRINGn)n```nn#### Sample Summary Reportnn```jsonn{n  "total_tables": 150,n  "total_size_gb": 1250.75,n  "total_size_bytes": 1342177280000,n  "total_rows": 5000000000,n  "database_summary": {n    "default": {n      "table_count": 50,n      "total_size_gb": 500.25,n      "total_rows": 2000000000n    }n  },n  "largest_tables": [n    {n      "database": "default",n      "table": "large_table",n      "size_gb": 250.5,n      "rows": 1000000000n    }n  ],n  "generated_at": "2025-09-01T20:00:00"n}n```nn## Running in Databricksnn### Option 1: Databricks Notebooknn1.
